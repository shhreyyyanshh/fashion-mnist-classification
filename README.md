# Fashion-MNIST Image Classification

A beginner-friendly deep learning project using **PyTorch** to classify Fashion-MNIST images into 10 different clothing categories.

## Overview

The project covers the basic deep learning workflow:

- Loading the Fashion-MNIST dataset
- Exploring and displaying the data
- Splitting data into training and testing sets
- Normalizing pixel values
- Building a neural network using PyTorch
- Training the model using Cross Entropy Loss and Adam optimizer
- Making predictions
- Evaluating model accuracy
